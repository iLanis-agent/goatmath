# GoatMath

The honest math of keeping backyard goats: herd minimums and space, winter hay in bales, realistic milk yield per lactation, cost per gallon, and whether your fence counts.

Static site. No build, no backend, no tracking. Open `index.html`.

- **Engine:** `engine.js` - pure functions, tested in Node.
- **App:** `app.html` - five cards (herd/space, hay, milk, cost, fence) with presets.

Part of the App Factory: https://github.com/iLanis-agent/app-factory
